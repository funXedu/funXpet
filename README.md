# funXtoy - 互動玩具
基於[`小智聊天機器人`](https://github.com/78/xiaozhi-esp32)，低成本、DIY（自己動手做）的互動玩具項目，專為教育用途設計。

---

## 🎯 功能特點

- 體感音效
- 語音交互
- 自動睡眠
- 搖晃喚醒

## 🔧 硬體製作

### 所需電子元件
| 元件 | 規格 | 數量 |
|------|------|------|
| **開發板** | LOLIN32_lite 或 LOLIN32 (ESP32 4MB) | 1個 |
| **姿態傳感器** | MPU6050 (I2C) | 1個 |
| **觸摸傳感器** | 銅箔 或 鋁箔 | 4 片 |
| **麥克風** | INMP441 (I2S) | 1個 |
| **音頻放大器** | MAX98357A (I2S) | 1個 |
| **喇叭** | 3W | 1個 |
| **電池** | 3.7V 鋰電池 | 1個 |
| **按鈕開關** | 2接點 | 1個 |
| **電阻** | 相同阻值(例如 10kΩ) | 3個 |
* 使用LOLIN32開發板只需1個電阻
* 使用3接點按鈕模組可少1個電阻

### 所需工具
* `焊接工具`: 用於製作電路板
* `雙面膠` 或 `熱熔膠槍`: 用於固定電路板
* `USB 訊號線`: 用於程序下載

### 連線圖
```
ESP01S (IO2) →  傾斜開關 (訊號線S)
ESP01S (IO0) →  WS2812B 燈帶 (訊號線DIN)
ESP01S (RST) →  按鈕開關 (+)
ESP01S (GND) →  穩壓模組 (GND) + 傾斜開關 (GND) + 燈帶 (GND) + 充電模組 (-) + 鋰電池 (-) + 按鈕開關 (-) 
ESP01S (3.3V) → 3.3V穩壓模組 (Vout) + 傾斜開關 (VCC)
充電模組 (+) → 鋰電池 (+) + 撥動開關（+）
5V穩壓模組 (Vin)  → 撥動開關 (-)
5V穩壓模組 (Vout) → WS2812B 燈帶 (VCC) + 3.3V穩壓模組 (Vin)
```

### 接線注意事項
- LOLIN32開發板自帶電量檢測電路，不須另外焊接分壓電阻。
- 使用3接點按鈕模組需確認接線方式，確保按鈕開關按下時訊號線輸出高電位，沒按時輸出低電位。
- 務必做好絕緣。


### 燒錄韌體

  * 下載[`韌體檔案`](firmware1m.bin)
  * 以 `USB 訊號線` (不是充電線) 連接 `電腦` 和 `開發板` 
  * 點選進入 [`燒錄工具網頁版`](https://espressif.github.io/esptool-js/)
  * 點選網頁 `Connect` 按鈕，選擇正確的`USB端口` 後點選 `連線`
  * `Flash Address` 設為 `0x0`
  * 點選 `選擇檔案` 按鈕後選擇之前下載的韌體檔
  * 點選網頁 `Program` 按鈕後開始燒錄韌體
  * 燒錄完成後點選網頁 `Disconnect` 按鈕
  * 拔除 `USB` 線

## 💻 設定 

### 設定WiFi基地台
1. 上電後以電腦或手機搜尋 WiFi 網絡：`Xiaozhi-XXXXXX`
2. 在瀏覽器中訪問：`http://192.168.4.1/`
3. 在網頁中點選WiFi基地台SSID，輸入密碼 (可複選)
4. 點選 `保存` 按鈕
5. 開發板重啟后會自動連接到選定的WiFi網絡

### 設定雲端
1. 點選進入網頁 [`小智AI服務端`](https://xiaozhi.me/console/agents)
2. 點選 `新增裝置` 按鈕
![](/docs/11.jpg)
3. 輸入 `驗證碼` (會唸出來) 後點選 `確定` 按鈕
![](/docs/12.jpg)
4. 點選 `配置角色` 按鈕後進入配置角色頁面
5. 依需求修改角色配置後點選 `儲存` 按鈕

## 🐻 開膛剖腹
![](/docs/3.jpg)
- 打開絨毛玩具
- 將銅箔(或鋁箔)縫在絨毛玩具相對應位置內面，作為觸摸傳感器。
- 姿態傳感器Y軸朝頭部，X軸朝左臂，Z軸朝面前。固定於絨毛玩具內。
- 麥克風和喇叭固定於玩具內，視需要在絨毛玩具相對應位置表面刺些小洞。
- 按鈕開關可固定於玩具內鼻頭等位置。
- usb 充電接口要露出。
- 縫合

## 📅 使用說明

- 設備上電後會自動連網。
- 摸/壓/打/搖晃/拋接/倒吊時會發出聲音。
- 點擊鼻頭(按鈕)可以切換聆聽/待命狀態。
- 聆聽狀態下可語音交互。
- 長時間無動作自動睡眠，按鈕或搖晃喚醒。
- 可問它電量以決定充電時機。
- 雖然會自動將體感事件上傳雲端，但服務端並不會處理，因此無法更好的交互。
